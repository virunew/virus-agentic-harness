## Purpose

Operator prompts are not agent policy.

Files placed here later may hold prompt text a person pastes into a tool. They do not override `CLAUDE.md`, `AGENTS.md`, the Cursor rule, or `docs/references/agent-operating-policy.md`. If a prompt and a policy file disagree, the policy file wins, and simplicity still sits above the rest of the method.
